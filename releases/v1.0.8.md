# Sway 1.0.8

- Fixed the CI build and release failure caused by a runtime-verification tool that was not installed on GitHub's macOS runners.
- Runtime verification now uses only tools included with macOS and accepts exactly the one documented ad-hoc signing entitlement. Missing, incorrectly typed, or extra entitlements fail verification.
- Both CI workflows now test that verification with disposable signatures and a system-tools-only environment, including unsigned binaries and invalid runtime configurations.

The failed v1.0.7 tag is preserved. This corrected release uses a new version and tag; no protected history is rewritten. App controls, gestures, and the update-signing key are unchanged.

Sway remains ad-hoc signed and unnotarized. Install from this repository's DMG or ZIP once if you still have a copy pointing to the previous private repository. Future releases support signed in-app installation.
