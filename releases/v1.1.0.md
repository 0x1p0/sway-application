# Sway 1.1.0

## Your trackpad, more possibilities

Choose from **26 edge actions, plus Off**, with a searchable, categorized action library in **Settings → Gestures**. Assign either side independently; optional top edges use the same library. Existing brightness and volume assignments stay unchanged.

- **Display and keyboard:** display brightness and keyboard backlight.
- **Audio and microphone:** output volume, input gain, speaker mute, and supported microphone hardware mute.
- **Media:** previous/next track and play/pause.
- **Navigation:** tabs, back/forward, zoom, page up/down, and document start/end.
- **Windows and desktops:** switch desktops, Mission Control, App Exposé, show desktop, switch apps, cycle windows, full screen, minimize, and hide app.
- **Tools:** Spotlight, screenshot toolbar, Emoji & Symbols, and a custom pair of up/down keyboard shortcuts.

Each action explains its directions and requirements. Unsupported hardware controls are clearly marked. Repeating commands follow gesture travel with rate limits; one-shot commands require lifting your fingers before another activation. Commands stop when the foreground app changes. Safe test mode never executes actions or changes hardware.

## Microphone controls without recording

Sway adjusts properties of the current default input without opening a recording stream. Input gain never unmutes the device. Hardware mute is available only when the driver exposes a readable, writable control, and status is confirmed by readback. This is not a universal privacy switch: other microphones and an app's own mute state are separate.

Keyboard lighting depends on supported hardware and macOS lighting policies. App navigation uses standard shortcuts, so support depends on the foreground app, keyboard layout, and your macOS shortcut settings. Live gesture feel and shortcut compatibility still need checking on your own Mac; automated tests do not replace that hardware check.

## Install or update

Download the universal DMG for Apple Silicon and Intel, or choose **Install update** in Sway's Software updates settings. The release includes a signed update ZIP, signed update feed, and SHA-256 checksums.

The persistent Sway app-signing identity and update-signing key are unchanged. This release remains self-signed and unnotarized, with Hardened Runtime enabled; it is not an Apple Developer ID release. See the README or the installer's First Launch guide if macOS asks you to allow the app.
