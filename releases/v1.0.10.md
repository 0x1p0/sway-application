# Sway 1.0.10

- Fixed clipped three-dot options: the native menu bar popover now grows and shrinks with its contents, including on the first click.
- Changed the Dock option to **Show in Dock while windows are open**. Closing the last Sway window hides its running Dock icon while controls and gestures remain available from the menu bar.
- Reopening Sway restores an existing window, including a minimized one, or opens Controls when no window remains. The setup guide still returns if setup is unfinished.
- Added **Open Controls…** to the three-dot options for easy access to the standalone controls window.
- Added regression checks for repeated popover resizing and window/Dock lifecycle behavior, plus an isolated native light/dark presentation check.

A Dock icon pinned with macOS's **Keep in Dock** setting stays pinned; turn off that system setting if you want it to disappear entirely.

Sway remains ad-hoc signed and unnotarized. Download the DMG or use **Install update…** from a compatible version already installed from this repository. Update signing and the release approval process are unchanged.
