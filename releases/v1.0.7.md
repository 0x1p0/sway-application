# Sway 1.0.7

The first release from **sway-application**, starting with a fresh source history.
Install this version from its DMG or ZIP once; copies from the previous private
repository cannot discover the new update feed. Future releases support signed
in-app installation from Software updates.

## Stronger app and release protections

- Hardened Runtime is now enabled and verified in packaged builds. Ad-hoc distribution retains only the library-validation exception needed to load Sparkle; unnecessary Apple Events permission has been removed.
- Builds and tests run without release secrets or repository-write permission. Signing and publication move to a fresh runner behind the maintainer's release approval.
- Signing tools come from protected main and use Apple's CryptoKit directly. The signing process never extracts or executes the app archive and installs no third-party packages.
- The existing update public key is unchanged. Update archives and feeds remain signed, and modified updates are rejected.
- Repository controls now protect main and release tags, check for leaked credentials and vulnerable dependencies, and make future published releases immutable.

Sway remains ad-hoc signed, not Developer ID signed or notarized. The initial Gatekeeper warning is still expected; see the README for trusted-install guidance.
