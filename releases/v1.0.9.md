# Sway 1.0.9

This release includes the verified CI fix: Hardened Runtime checks use only tools included with macOS, with regression coverage for missing runtime protections and unexpected entitlements.

The earlier v1.0.8 tag pointed to the initial 1.0.7 source, so publication correctly stopped on the version mismatch. Both old tags remain unchanged. This release uses a new version and tag on the corrected source.

App controls, gesture behavior, and the update-signing key are unchanged. Release builds still run tests before signing on a separate, approval-protected runner.

Sway remains ad-hoc signed and unnotarized. If your installed copy points to the previous private repository, install this version's DMG or ZIP once. Future releases support signed in-app installation.
